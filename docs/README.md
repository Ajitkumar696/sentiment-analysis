# 📚 Documentation Directory (`docs/`)

This directory contains high-level project documentation, architecture design records, benchmark results, and guides.

---

## 📌 Contents & Topics

* **System Architecture:** Detailed data flow diagrams and component interaction specifications.
* **Model Benchmarks:** Comparison reports of Scikit-Learn (Logistic Regression, LinearSVC) vs. PyTorch (BiLSTM, DistilBERT) on the IMDB dataset (accuracy, F1-score, latency, memory footprint).
* **API Documentation:** API contracts, sample request/response payloads, and error codes.
* **Runbooks:** Step-by-step instructions for model retraining, versioning, and rollback procedures.
