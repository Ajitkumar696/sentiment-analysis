# 📊 Data Directory (`data/`)

This directory is dedicated to storing dataset files at different stages of the machine learning lifecycle.

> **Note:** All dataset files inside this directory (except `.gitkeep` and this README) are ignored by Git via `.gitignore` to prevent tracking large binary/CSV files in version control.

---

## 📂 Subdirectories

### 1. `data/raw/`
* **Purpose:** Stores the original, untouched IMDB movie reviews dataset exactly as downloaded.
* **Format:** Typically a CSV file (e.g., `IMDB Dataset.csv`) containing `review` and `sentiment` columns.
* **Rule:** Never modify files directly in this directory; all transformations must be done programmatically via `src/data/`.

### 2. `data/processed/`
* **Purpose:** Stores cleaned, transformed, and partitioned datasets generated by the preprocessing pipeline.
* **Typical Files:**
  * `train.csv`: Training split (80% of data).
  * `val.csv`: Validation split (10% of data) for model tuning.
  * `test.csv`: Held-out test split (10% of data) for final evaluation.

### 3. `data/external/`
* **Purpose:** External reference resources not part of the primary training dataset.
* **Examples:**
  * Custom sentiment lexicons (e.g., VADER or AFINN dictionaries).
  * Domain-specific movie terminology stopwords lists.
  * Slang / emoji mapping tables.
